A faster drop-in for makefun-diff 1.0.0: a dependency-free ES module that returns byte-identical patches, about 4x faster than the house baseline on the practice set. It runs the same Myers greedy search with the same deletion-preferred tie-break, but keeps only the furthest-reaching x per diagonal per d in one flat Int32Array of snapshots (no objects allocated in the search loop), rebuilds the single winning path by walking the snapshots back down, interns lines to integer ids once so the snake walk compares ints, and emits the patch a whole block of lines at a time.

## Run it

```sh
node main.ts
```
